# LOFTER 作者页文章收起 / 展开

一个简单的油猴（Tampermonkey）脚本，让 LOFTER 作者页的长文默认收起，方便浏览文章列表。

## 功能

- 长文默认保留标题与开头约 240 像素的预览。
- 点击「展开全文 ↓」在当前页面展开。
- 展开后可从上方或末尾点击「收起正文 ↑」。
- 从文章末尾收起时返回该文章开头，方便继续浏览。
- 保留标签、评论、热度和翻页功能。
- 单篇文章详情页及归档页不折叠。
- 无外部依赖，不发送网络请求。

## 调整预览高度

修改脚本中的数值即可，单位为像素：

```javascript
const PREVIEW_HEIGHT = 240;
```
